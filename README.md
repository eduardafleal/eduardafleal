## Eduarda Leal

**Analista de Dados · SQL · Power BI · Python · Salvador, BA**

Atuo com dados em ambiente de meios de pagamento: transações, autenticação,
emissão de cartões e disponibilidade de serviço. Meu trabalho é transformar dado
operacional em indicador que sustenta decisão, e garantir que esse número seja
confiável antes de alguém usá-lo.

Boa parte do que faço é diagnóstico: descobrir por que um valor não bate, por que
uma atualização falhou ou de onde veio uma inconsistência. Sempre com evidência,
nunca com suposição.

### Em que atuo

**Modelagem e BI**
Modelagem dimensional (Star Schema), medidas DAX, Power Query (M), publicação e
governança no Power BI Service, gateways e ciclos de refresh.

**SQL e banco de dados**
PostgreSQL. Queries analíticas com JOIN, agregações, subqueries e window functions
(ROW_NUMBER, LEAD). Validação de schema antes de consultar e leitura de plano de
execução (EXPLAIN ANALYZE) para investigar query lenta.

**Automação e monitoramento**
Python consumindo a API do Power BI para registrar falhas de atualização de
datasets em banco, com autenticação via Service Principal e carga idempotente.
Alertas automatizados em Power Automate.

**Arquitetura de dados**
Camadas Bronze, Silver e Gold (Medallion) e camada semântica sobre o Data Warehouse.
